# Расчет метрик и проверка гипотезы для сервиса "Яндекс книги" (осень и начало зимы 2024 года)
## Описание проекта
Проект посвящен расчету метрик в SQL для команды маркетинга сервиса "Яндекс книги" и проверки гипотезы в Python, выдвинутой на основе анализа метрик. 
## Цели и задачи
**Цель:** сформировать четкую картину пользовательского поведения на основе метрик
**Задачи:**

1. Рассчитать метрики в SQL: MAU авторов, MAU произведений, Retention Rate, LTV, среднею выручку прослушанного часа.
2. Интерпретировать результаты.
3. Сравнить активность пользователей из Санкт-Петербурга и Москвы.
4. Проверить гипотезу: пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.
## Основные выводы
1. Автор, который собрал больше всего уникальных читателей в ноябре: Андрей Усачёв (MAU 7107).
2. Все 3 самых популярных произведения в ноябре написаны для детей.
3. На пятый день активности Retention Rate составил 47% — это минимальное значение.
4. В Москве больше пользователей и их LTV выше по сравнению с пользователя из Санкт-Петербурга.
5. Средняя выручка за час активности падает в течение осени (в сентябре: 61 рубль 70 копеек, в ноябре — уже 51 рубль 4 копейки).
6. Статистически не получилось доказать, что активность пользователей из Санкт-Петербурга выше, чем пользователей из Москвы
## Структура проекта
- `sql/` — SQL‑скрипты с запросами для расчёта требуемых метрик.
- `notebook/` — Jupyter‑ноутбук с проверкой гипотезы на Python.
- `README.md` — текущий файл с описанием проекта.
## Используемые инструменты и технологии
- **Данные:** данные о чтении и прослушивании контента в сервисе Яндекс Книги, которые включают информацию о пользователях, платформах, времени, длительности сессий и типах контента (период с 1 сентября по 11 декабря 2024 года).
- **Расчёт метрик:** SQL
- **Проверка гипотезы:** Python (pandas, matplotlib, scipy.stats)
