# Анализ результатов A/B-тестирования для магазина спортивных товаров
## Описание проекта
Чтобы привлечь новых клиентов и увеличить число продаж, владельцы интернет-магазина спортивных товаров разработали новую версию сайта и протестировали его на части пользователей. По задумке, это решение доказуемо повысит количество пользователей, которые совершат покупку. Необходимо проверить корректность проведения теста и его результатов. Гипотеза заключается в следующем: упрощение интерфейса приведёт к тому, что в течение семи дней после регистрации в системе конверсия зарегистрированных пользователей в покупателей увеличится как минимум на три процентных пункта.
## Цели и задачи
**Цель:** проверить гипотезу о влиянии упрощения интерфейса на конверсию

**Задачи:**
1. Загрузить данные теста.
2. Оценить корректность проведения.
3. Оценить результаты.
4. Сформулировать вывод.

## Основные выводы
Конверсия в группе В выросла примерно на 2.2 п.п. Для проверки был выбран Z-тест пропорций, который позволяет оценить значимость изменения конверсии (долевой метрики). Тест подтвердил значимость этого изменения. Однако ожидаемый эффект (изменение конверсии на 3 п.п.) достигнут не был.
