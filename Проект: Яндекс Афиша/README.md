# Аналитика продаж билетов в сервисе «Яндекс Афиша» (осень 2024 года)

## Описание проекта

Проект посвящён аналитике продаж билетов в сервисе «Яндекс Афиша» в период с  июня по ноябрь 2024 года. В центре внимания — неравномерная динамика продаж: на одни мероприятия спрос растёт, на другие — падает. Цель проекта — выявить причины этих изменений и дать команде продукта обоснованные инсайты для подготовки к периоду распродаж и новогодних акций.

В рамках проекта решаются две взаимосвязанные задачи:

- построение аналитического дашборда в Yandex DataLens для оперативного мониторинга ключевых бизнес‑показателей;
- углублённый исследовательский анализ в Python для проверки гипотез и выявления скрытых закономерностей.

## Цели и задачи
**Цель**: сформировать комплексную картину динамики продаж и поведения пользователей, чтобы команда продукта могла принимать взвешенные решения в предпраздничный период.

**Задачи**:

1. **Отслеживать динамику ключевых бизнес‑показателей:** ежедневный объём продаж, выручку, количество заказов, средний чек.
2. **Анализировать популярность мероприятий:** выявить категории событий, которые набирают или теряют популярность осенью 2024 года.
3. **Изучить структуру выручки:** распределение по категориям мероприятий, площадкам и организаторам.
4. **Сравнить поведение пользователей на разных устройствах:** проверить гипотезу о различиях в активности пользователей мобильных устройств и стационарных компьютеров.
5. **Проверить влияние сезонности и возможных сдвигов аудитории:** оценить, насколько наблюдаемые тренды обусловлены сезонными факторами либо изменением состава и предпочтений аудитории.
6. **Сформулировать практические выводы и рекомендации для продуктовой команды.**

## Результаты проекта
1. Расчет основных показателей в SQL:
   
    - получение общих данных;
    - выручки в разрезе типа мероприятий;
    - выручка в разрезе типа устройства;
    - динамика изменения значений;
    - выделение топ-сегментов.
      
3. Аналитический дашборд в Yandex DataLens, включающий:
   
    - абсолютные значения показателей (выручки, количества заказов, общего числа пользователей, средней стоимости заказа);
    - недельную динамику ключевых метрик (суммарной выручки, количества заказав, средней выручки с заказа);
    - распределение выручки по типу мероприятия и типу устройства;
    - рейтинг площадок, регионов и событий по выручке;
    - фильтры по валюте, дате, типу события и региону для гибкой настройки отчётов.
      
5. Исследовательский анализ в Jupyter Notebook на Python, содержащий:
   
    - предобработку и очистку данных, проверку на пропуски и аномалии, добавление новых столбцов;
    - анализ распределения заказов по сегментам и их сезонные изменения;
    - анализ активности пользователей осенью;
    - выделение ключевых регионов и партнеров, которые приносят наибольшую выручку;
    - статистическая проверка двух гипотез относительно активности пользователей мобильных и стационарных устройств;
    - выводы об изменении пользовательских предпочтений и факторах, влияющих на динамику продаж.
  
## Основные выводы и рекомендации

1. В данных наблюдается сезонность — осенью количество заказов увеличивается
2. Осенью наблюдается сильное увеличение спроса на категории спорт и театр. На мероприятия с возрастным ограничением "0" спрос так же растет. Команде продукта есть смысл сделать упор на продвижении мероприятий этих типов в осенний период.
3. В данных наблюдается интересный инсайт: в будние дни приток новых пользователей в сервис почти в два раза больше, чем в выходные.
4. Наибольшую часть в структуре выручки занимают концерты (примерно 56%) и театры (примерно 23%).
5. Пользователи мобильных устройств в среднем делают больше заказов. А пользователи стационарных устройств делают заказы чаще. 

## Структура проекта
- `sql/` — SQL‑скрипты с запросами для расчёта ключевых показателей.
- `notebook/` — Jupyter‑ноутбук с исследовательским анализом на Python.
- `datalens/` — описание и настройки дашборда (скриншоты, ссылка).
- `README.md` — текущий файл с описанием проекта.

## Используемые инструменты и технологии
- **Данные:** выгрузки из внутренних систем «Яндекс Афиши» в анонимизированном виде (информация о заказах, мероприятиях, площадках, организаторах, устройствах пользователей).
- **Аналитика и визуализация:** Yandex DataLens.
- **Исследовательский анализ:** Python (pandas, numpy, matplotlib, seaborn, scipy.stats).
- **Расчёт метрик:** SQL (для извлечения и агрегации данных).
- **Среда разработки:** Jupyter Notebook.
