# Аналитика продаж билетов в сервисе «Яндекс Афиша» (осень 2024)

## Описание проекта: 

Проект посвящён аналитике продаж билетов в сервисе «Яндекс Афиша» в период с  июня по ноябрь 2024 года. В центре внимания — неравномерная динамика продаж: на одни мероприятия спрос растёт, на другие — падает. Цель проекта — выявить причины этих изменений и дать команде продукта обоснованные инсайты для подготовки к периоду распродаж и новогодних акций.

В рамках проекта решаются две взаимосвязанные задачи:

- построение аналитического дашборда в Yandex DataLens для оперативного мониторинга ключевых бизнес‑показателей;
- углублённый исследовательский анализ в Python для проверки гипотез и выявления скрытых закономерностей.

## Цели и задачи
**Цель**: сформировать комплексную картину динамики продаж и поведения пользователей, чтобы команда продукта могла принимать взвешенные решения в предпраздничный период.

**Задачи**:

1. **Отслеживать динамику ключевых бизнес‑показателей:** ежедневный объём продаж, выручку, количество заказов, средний чек.
2. **Анализировать популярность мероприятий:** выявить категории событий, которые набирают или теряют популярность осенью 2024 года.
3. **Изучить структуру выручки:** распределение по категориям мероприятий, площадкам и организаторам.
4. **Сравнить поведение пользователей на разных устройствах:** проверить гипотезу о различиях в активности пользователей мобильных устройств и стационарных компьютеров (частота заказов, средний чек, предпочитаемые категории мероприятий).
5. **Проверить влияние сезонности и возможных сдвигов аудитории:** оценить, насколько наблюдаемые тренды обусловлены сезонными факторами либо изменением состава и предпочтений аудитории.
6. **Сформулировать практические выводы и рекомендации для продуктовой команды.**

## Структура проекта
- `sql/` — SQL‑скрипты с запросами для расчёта ключевых показателей.
- `notebook/` — Jupyter‑ноутбук с исследовательским анализом на Python.
- `dashboard/` — описание и настройки дашборда (скриншоты, ссылка).
- `README.md` — текущий файл с описанием проекта.

## Используемые инструменты и технологии
- **Данные:** выгрузки из внутренних систем «Яндекс Афиши» в анонимизированном виде (информация о заказах, мероприятиях, площадках, организаторах, устройствах пользователей).
- **Аналитика и визуализация:** Yandex DataLens.
- **Исследовательский анализ:** Python (pandas, numpy, matplotlib, seaborn, scipy.stats).
- **Расчёт метрик:** SQL (для извлечения и агрегации данных).
- **Среда разработки:** Jupyter Notebook.
