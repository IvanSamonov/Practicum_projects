# Описание дашборда

## Дашборд включает в себя: 
1. **Значения индикаторы:**
   
   - итоговая выручка
   - общее количество заказов
   - общее число пользователей
   - средняя стоимость одного заказа
2. **Кольцевые диаграммы структуры выручки:**
   
   - по типу мероприятия
   - по типу устройства
3. **Линейные графики, которые показывают недельную динамику:**
   
   - суммарной выручки
   - количества заказов
   - средней выручки с заказа
4. **Наиболее популярные (по суммарной выручке):**
   
   - регионы
   - события
   - площадки
5. **Селекторы по:**
    
   - валюте
   - дате
   - типу события
   - региону
