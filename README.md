# Проект: Яндекс Афиша
https://github.com/IvanSamonov/Practicum_projects/tree/796dbe36e43a40964a41a229784b32b6eb562f66/%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%3A%20%D0%AF%D0%BD%D0%B4%D0%B5%D0%BA%D1%81%20%D0%90%D1%84%D0%B8%D1%88%D0%B0
## Описание: 
- **Цель проекта** — проанализировать динамику продаж билетов в «Яндекс Афише» летом и осенью 2024 года и выявить факторы роста/падения спроса перед зимними праздникам.
- **Ключевые задачи** — отследить бизнес‑метрики, оценить популярность категорий мероприятий, изучить структуру выручки и сравнить поведение пользователей на мобильных и стационарных устройствах.
- **Основные инструменты** — Yandex DataLens (дашборд), Python (исследовательский анализ в Jupyter Notebook), SQL (расчёт показателей).

# Анализ бизнес-метрик для сервиса доставки еды (май — июнь 2021)
https://github.com/IvanSamonov/Practicum_projects/tree/17dbac921c9f7e901e660bdea99722a8d66c0368/%D0%90%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7%20%D0%B1%D0%B8%D0%B7%D0%BD%D0%B5%D1%81-%D0%BC%D0%B5%D1%82%D1%80%D0%B8%D0%BA%20%D0%B4%D0%BB%D1%8F%20%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%B0%20%D0%B4%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D0%B8%20%D0%B5%D0%B4%D1%8B
## Описание:
- **Цель проекта** — разработать аналитический дашборд в DataLens с ключевыми бизнес‑метриками для оценки состояния клиентской базы сервиса доставки еды «Всё.из.кафе» в Саранске и подготовить на его основе аналитический отчёт.
- **Ключевые задачи** — подготовить QL‑запросы и визуализации (графики) для метрик DAU, Conversion Rate, средний чек, LTV и Retention Rate; собрать дашборд с наглядными графиками, позволяющими отслеживать динамику, выявлять закономерности и аномалии; проанализировать визуализации и сформулировать выводы в аналитической записке.
- **Основные инструменты** — Yandex DataLens (дашборд), SQL (расчёт показателей)
