# Проект: Яндекс Афиша
https://github.com/IvanSamonov/Practicum_projects/tree/796dbe36e43a40964a41a229784b32b6eb562f66/%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%3A%20%D0%AF%D0%BD%D0%B4%D0%B5%D0%BA%D1%81%20%D0%90%D1%84%D0%B8%D1%88%D0%B0
## Описание: 
- **Цель проекта** — проанализировать динамику продаж билетов в «Яндекс Афише» летом и осенью 2024 года и выявить факторы роста/падения спроса перед зимними праздникам.
- **Ключевые задачи** — отследить бизнес‑метрики, оценить популярность категорий мероприятий, изучить структуру выручки и сравнить поведение пользователей на мобильных и стационарных устройствах.
- **Основные инструменты** — Yandex DataLens (дашборд), Python (исследовательский анализ в Jupyter Notebook), SQL (расчёт показателей).
