# Анализ бизнес-метрик для сервиса доставки еды (май — июнь 2021)
## Описание проекта

От сервиса доставки еды «Всё.из.кафе» поступил запрос: разработать дашборд, который с разных сторон отразит состояние клиентской базы в городе Саранске. На основе этого дашборда необходимо составить аналитический отчёт.

## Цели и задачи
**Цель:** разработать аналитический дашборд с ключевыми бизнес-метриками

**Задачи:**
1. Подготовить QL-запросы в DataLens для визуализации следующих метрик:
   
    - DAU — количество активных пользователей за день.
    - Conversion Rate — коэффициент конверсии.
    - Средний чек — средняя сумма покупки на пользователя.
    - LTV — совокупная ценность клиента за период.
    - Retention Rate — коэффициент удержания пользователей.
2. Создать визуализации в DataLens:
   
    - Для каждой метрики подготовить график для наглядного анализа.
    - Убедиться, что визуализации отражают динамику показателей, а также позволяют выявлять закономерности и аномалии.
3. На основе этих запросов создать дашборд, который включает понятные графики для указанных выше метрик.
4. Проанализировать результаты визуализаций и подготовить выводы в аналитической записке

## Структура проекта
- `sql/` — SQL‑скрипты с запросами для расчёта ключевых показателей.
- `datalens/` — описание и настройки дашборда (скриншоты, ссылка).
- `README.md` — текущий файл с описанием проекта.

## Используемые инструменты и технологии
- **Данные:** журнал логов пользователей сервиса, рекламные затраты по дням, справочник партнёрских сетей, справочник блюд, справочник городов.
- **Аналитика и визуализация:** Yandex DataLens.
- **Расчёт метрик:** SQL.
